# Context teaching visuals

## The same task needs information at different lifetimes

Slide body: This pagination example needs different information as the work moves. The goal and latest failure belong in active context. A checkpoint keeps the current task recoverable. The stable test command can help future tasks. Saved information enters active context again when the agent loads it.

Caption: Information has a lifetime, not a permanent category.

## Compaction makes a continuation record

Slide body: This is an illustrative worked example, not a recorded run. The agent read the pagination code, ran the boundary test, changed the end index, and saw the same failure. The continuation record keeps the exact goal, verified output, unresolved failure, and next inspection. The raw trace remains separate.

Caption: Keep what the next step needs. Keep the raw trace somewhere else.

The `.excalidraw` files are the editable sources. The SVG files are editable vector exports. PNG files are 1920×1080 slide previews.
