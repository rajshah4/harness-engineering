Workshop 6: Single agent versus multiple agents

Question: what changes when we use multiple agents? First compare the two architectures: one agent uses repository/test tools directly; the worker-plus-validator system delegates checking to a separate context and returns evidence to the repair owner. The validator works after the repair in this example.

Then introduce the task: fix the shared counter so 50 concurrent jobs reliably produce 50 while work stays concurrent. Both architectures receive identical starter files, model, task, protected tests, external checker and a total 30-call ceiling. Finally compare correctness, wall time, calls and tokens.
